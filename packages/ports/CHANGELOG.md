# @noy-db/ports

## 0.8.0

Initial release — the six conformance kits consolidated into one package with one subpath per hub port (`@noy-db/ports/to`, `/as`, `/at`, `/on`, `/by`, `/capsule`). Exported function names are unchanged from `@noy-db/test-adapter-conformance`, `test-format-conformance`, `test-sealer-conformance`, `test-ceremony-conformance`, `test-mesh-conformance` and `test-capsule-conformance`, which now re-export from here and are deprecated in favour of it.
