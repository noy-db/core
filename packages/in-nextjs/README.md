# @noy-db/in-nextjs

[![npm](https://img.shields.io/npm/v/%40noy-db/in-nextjs.svg)](https://www.npmjs.com/package/@noy-db/in-nextjs)

> Next.js App Router helpers for noy-db

Part of [**`@noy-db/hub`**](https://www.npmjs.com/package/@noy-db/hub) — the zero-knowledge, offline-first, encrypted document store.

## Install

```bash
pnpm add @noy-db/hub @noy-db/in-nextjs
```

## What it is

Next.js App Router helpers for noy-db — server components, route handlers, client hooks, and cookie-based session. Thin bridge that composes @noy-db/in-react with Next's cookies()/headers() APIs.

## Status

**Pre-release** (`0.1.0-pre.1`). API may change before `1.0`.
