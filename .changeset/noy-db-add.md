**`noy-db add <package>` and `noy-db add --list [to|in|on|as|by|at]`** — the landscape, one verb (family#118). `add` installs a `@noy-db/*` package with the package manager your lockfile implies, wires it where a config can be edited (an `in-nuxt` module into `nuxt.config`), prints the import to paste otherwise, and **says what trust boundary the layer crosses** — `to-` sees ciphertext only, `as-` sees plaintext by design, `at-` lets a host you control decrypt a slice. `--list` reads the catalog the docs site publishes (`noy-db.lanna.ai/catalog.json`, generated from `features.yaml`) and falls back to the snapshot this version ships, so it works offline. `--dry-run` and `--offline` do what they say. `noy-db add <collection>` (a bare word) still scaffolds a collection.
